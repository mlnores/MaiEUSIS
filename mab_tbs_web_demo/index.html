Choose a demonstration

Both demonstrations preserve the original choice, reward and scoring rules, with fewer trials. Use a physical keyboard or click the available alternatives. Session data are stored locally in this page until you download or close it.

Software markers are recorded at screen presentation and response times using performance.now(). These are not EEG triggers or recorded ERPs. Browser/display latency is not calibrated, and timing must not be treated as laboratory-equivalent.

For MAB, outcome probabilities are hidden during gameplay but included in the downloadable researcher logs. For TBS, the safe/risky amounts and probabilities are displayed and both recorded even when neither option is chosen.

What is recorded?

One detailed record per trial, one record per available option per trial (including unselected options), and event records for evaluation display, commitment, fixation, feedback display, timeouts, stage/volatility transitions and block completion. All records include session/trial identifiers and timing information. A complete JSON export retains nested snapshots, histories and full event details.

The original Python script sends parallel-port pulses; browser exports replace them with event-code labels plus timestamps at the actual software event. Event latency relative to the physical screen is not directly measurable here. These demonstrations are for collaborator familiarisation and software prototyping, not EEG/ERP acquisition or validated behavioural data collection.
